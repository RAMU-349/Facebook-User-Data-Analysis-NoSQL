# Facebook User Data Analysis Using NoSQL

## Project Overview
This project demonstrates Facebook-style user activity analysis using MongoDB, a NoSQL database, and Streamlit. It uses synthetic sample data rather than private Facebook user information.

## Objectives
- Store and manage user data using MongoDB.
- Perform Create, Read, Update, and Delete (CRUD) operations.
- Filter and sort user activity.
- Analyze user activity using aggregation.
- Display analytical results in an interactive dashboard.
- Export available results to CSV.

## Technologies Used
- Python
- MongoDB
- MongoDB Compass
- Streamlit
- Pandas

## Requirements
- Python installed
- MongoDB running locally
- Git

## Installation
Clone the repository:

    git clone https://github.com/RAMU-349/Facebook-User-Data-Analysis-NoSQL.git

Move into the project directory:

    cd Facebook-User-Data-Analysis-NoSQL

Install dependencies:

    pip install -r requirements.txt

## Run the Application
Start the Streamlit dashboard:

    streamlit run app.py

Open the local URL displayed in the terminal.

## Database
Database name: facebook_analysis

Collection name: facebook_users

The application uses synthetic sample data for demonstration.

## Main Features
- Interactive dashboard
- User data viewing
- CRUD operations
- Activity filtering
- Aggregation analysis
- CSV export

## Privacy
This project is an educational demonstration and does not use private Facebook account data.
